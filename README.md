# Cihan Plastik

Cihan Plastik (Çayeli / Rize) için tek sayfalık showroom sitesi. Düz HTML, CSS ve JavaScript; kurulum gerektirmez.

- `index.html`: sayfa
- `style.css`: tasarım ve animasyonlar
- `main.js`: WhatsApp linkleri, kategori sekmeleri, animasyonlar
- `img/`: görseller
- `CNAME`: alan adı (cihanplastik.tr)

GitHub Pages ile yayınlanır.
